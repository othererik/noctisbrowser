Noctis Browser

A zero-admin portable browser built on Electron and Chromium. Designed for disposable, ephemeral sessions with native Tor routing, client fingerprint noise, and real-time network inspection.

Core Architecture & Features

A breakdown of what Noctis includes under the hood.

Zero-Trace Ephemeral Sessions

Noctis boots into an isolated temporary folder in the operating system temp path (os.tmpdir()) with disk caching strictly disabled.

  • No persistent cookies, history, session tokens, or local storage.
  • On closing the browser, a detached multi-pass background reaper purges the temporary session directory.
  • The "Burn Identity" button allows an immediate cache wipe, circuit rotation, and tab reset mid-session.

Tor & Decentralized Protocol Routing

Native protocol handling without passing queries to clearnet search engines or leaking DNS lookups.

  • Bundles native Tor binaries for macOS, Linux, and Windows; auto-detects existing local Tor daemons.
  • Direct routing for .onion hidden services without external proxy configuration.
  • Built-in resolution support for .i2p, .loki, ipfs://, and .eth addresses.

Anti-Fingerprinting Protections

Reduces browser distinctiveness against automated canvas and hardware profiling scripts.

  • Viewport Letterboxing: Quantizes inner window dimensions to uniform 200×100 pixel buckets.
  • Canvas & Audio Noise: Introduces deterministic micro-jitter to canvas readbacks and audio context buffers.
  • Hardware Normalization: Spoofs uniform screen metrics, masks sensor APIs (gyroscope, accelerometer), and normalizes storage quota estimates.

Live Network Cockpit (noctis://monitor)

Provides Chrome DevTools Protocol request inspection and verifiable egress testing directly in the UI.

  • Live network request stream grouped by host and initiating script.
  • Built-in ad and tracker blocking backed by community blocklist feeds (Peter Lowe, StevenBlack).
  • 4-Hop Path Diagnostic: Checks unproxied baseline IP against the active tunnel exit IP to verify that traffic is actually masked before reporting success.

Privacy Vault (noctis://vault)

Transparent interface for inspecting and controlling what data is being held in memory and temporary storage.

  • Live file browser showing every ephemeral file currently written to the temp directory.
  • OS/hardware persona switcher (macOS Apple Silicon, Windows NVIDIA RTX, Linux AMD Radeon).
  • DNS-over-HTTPS (DoH) configuration with mandatory DNSSEC (AD=1) verification.

Zero-Admin Portability

Designed to run entirely in user space without touching system directories.

  • No installers, system registry changes, or elevated administrative privileges needed.
  • Can be run directly from an external USB drive or temporary workspace.
  • Includes platform-specific launchers that handle Linux user-space sandbox flags and macOS quarantine clearing.

Pros & Cons

Advantages

  • Truly disposable browsing Everything written during a session disappears when the process terminates. No manual browsing history clearing or private window management required.
  • Zero installation friction Unpack the folder and execute the launcher script. Runs on standard user accounts without sudo or administrator privileges.
  • Built-in Tor handling Routes .onion sites out of the box using bundled Tor binaries without needing manual SOCKS proxy setups.
  • Verifiable network routing The diagnostic tool tests both unproxied and proxied paths against external IP endpoints, ensuring the browser never falsely claims protection when a proxy fails.
  • Live observability The built-in CDP cockpit exposes network requests, active cookies, and temp files with transparency rarely present in consumer browsers.

Trade-offs & Limitations

  • Resource overhead (Electron & Chromium) Because it is built on Electron, cold start times are longer and RAM usage is substantially higher than lightweight native browsers or vanilla Firefox.
  • No persistent session state If you want to stay logged into email accounts, keep saved passwords, or retain tab layouts across reboots, Noctis is the wrong tool.
  • Website compatibility breakage Canvas perturbation, letterbox sizing, sensor blocking, and strict client-hint spoofing can cause layout glitches, CAPTCHA triggers, or broken functionality on complex web apps and DRM streaming sites.
  • Not a direct replacement for Tor Browser The official Tor Browser benefits from decades of Firefox C++ code modifications and a large, standardized user pool. Noctis provides convenient Tor routing and client-side noise, but it does not give the exact same mathematical anonymity set.
  • No extension ecosystem You cannot install extensions from the Chrome Web Store or Firefox Add-ons. You are limited to the built-in ad/tracker blocklists and privacy controls.
